# App icon provenance

The maintainer selected the illustrated island with bold sun rays (concept C)
on 2026-10-26. It was generated for SunPad with OpenAI's built-in image generation
tool. No reference image, game screenshot, extracted asset, official logo or
character artwork was supplied to the generator.

The prompt requested an original Isle Delfino-inspired tropical island seen
from offshore, with a curved sandy shoreline, green hillside, cream seaside
village and orange roofs, a palm tree, and a large golden sun with broad rays.
The style was crisp, colorful, cel-painted console-adventure illustration with
an ultramarine background, without text, characters, faces or official symbols.
This records the creative process; it does not claim legal clearance or Nintendo
endorsement.

The selected square artwork was resized without cropping to this opaque
1024×1024 PNG using macOS `sips`. It is the canonical icon master. Derived uses:

- iOS/iPadOS app icon and the README.
- `SunPadBrand.imageset` in the iOS and tvOS catalogs: 256×256 startup/setup art.
- `apple/macos/AppIcon.icns`: 16, 32, 128, 256 and 512 point entries at 1×/2×,
  generated with `sips` and `iconutil` for Finder, Dock and app identity.
- Apple TV layered icons and Top Shelf: see the [tvOS record](../../../tvos/Assets.xcassets/PROVENANCE.md).
- PadMint's `art/sunpad.png`: a 144×144 copy of this master, used by the library
  and game detail views on all PadMint hosts.

All derived artwork preserves the selected composition. No game files or
screenshots are bundled with these assets.
